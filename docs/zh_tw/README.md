# Vital Relics

[English](../../README.md) | [日本語](../ja_jp/README.md) | [简体中文](../zh_cn/README.md) | **繁體中文**

一個高度可設定的 Minecraft 遺物 Mod。

Vital Relics 目前仍持續維護與開發。

Vital Relics 加入各種可裝備遺物，從小型實用護符到極其強力的終局神器。

與許多遺物 Mod 不同，Vital Relics 的大部分行為都是**資料驅動**的。遺物 ID、材質、稀有度、屬性、被動效果、恢復、傷害規則、裝備位置、法術等都可以透過 `relics.json` 設定。

內建遺物只是預設設定。無需修改 Mod 的 Java 程式碼，你就可以修改、移除它們，或定義自己的遺物。

## 支援版本

| Minecraft | Loader |
|---|---|
| 1.20.1 | Forge |
| 1.21.1 | NeoForge |

Vital Relics 支援：

- Curios API 整合
- 可選的 Touhou Little Maid 整合
- 可設定的遺物定義
- 可設定的取得方式
- 可設定的主動法術
- 可設定的翻譯系統
