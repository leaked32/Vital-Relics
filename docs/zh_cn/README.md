# Vital Relics

[English](../../README.md) | [日本語](../ja_jp/README.md) | **简体中文** | [繁體中文](../zh_tw/README.md)

一个高度可配置的 Minecraft 遗物 Mod。

Vital Relics 目前仍在持续维护和开发。

Vital Relics 添加了各种可装备遗物，从小型实用护符到极其强力的终局神器。

与许多遗物 Mod 不同，Vital Relics 的大部分行为都是**数据驱动**的。遗物 ID、纹理、稀有度、属性、被动效果、恢复、伤害规则、装备位置、法术等都可以通过 `relics.json` 配置。

内置遗物只是默认配置。无需修改 Mod 的 Java 代码，你就可以修改、删除它们，或定义自己的遗物。

## 支持版本

| Minecraft | Loader |
|---|---|
| 1.20.1 | Forge |
| 1.21.1 | NeoForge |

Vital Relics 支持：

- Curios API 集成
- 可选的 Touhou Little Maid 集成
- 可配置的遗物定义
- 可配置的获取方式
- 可配置的主动法术
- 可配置的翻译系统
