# Vital Relics

[English](../../README.md) | **日本語** | [简体中文](../zh_cn/README.md) | [繁體中文](../zh_tw/README.md)

Minecraft 向けの高度に設定可能な遺物 Mod です。

Vital Relics は現在も継続的に保守・開発されています。

小さな便利系チャームから非常に強力なエンドゲーム向けアーティファクトまで、装備可能なさまざまな遺物を追加します。

多くの遺物 Mod と異なり、Vital Relics の大部分は **データ駆動** です。遺物 ID、テクスチャ、レアリティ、属性、パッシブ効果、回復、ダメージ規則、装備位置、スペルなどを `relics.json` から設定できます。

同梱されている遺物はあくまで既定設定です。Java コードを変更せずに既存遺物を編集・削除したり、独自の遺物を定義したりできます。

## 対応バージョン

| Minecraft | Loader |
|---|---|
| 1.20.1 | Forge |
| 1.21.1 | NeoForge |

Vital Relics は以下をサポートします。

- Curios API 連携
- 任意の Touhou Little Maid 連携
- 設定可能な遺物定義
- 設定可能な入手方法
- 設定可能なアクティブスペル
- 設定可能な翻訳
